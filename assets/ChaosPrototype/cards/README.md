# 卡牌占位图

现有每种卡牌各有一个独立的 500×380 PNG。将同名文件替换为自己的图片后重新打包即可；无需修改卡牌代码。推荐保持 500×380，避免拉伸。

素材来源：战双帕弥什 BWIKI，原游戏美术权益归原权利人。图标保持比例居中置于深色底；未冒充最终插画。完整来源地址见 `sources.json`。

基础球暂用鸦羽对应颜色球图标；角色球用各机体对应颜色图标。原作多个招式共享图标时，本项目仍各存一份，便于分别替换。主动超算、极限闪避、风的视线暂无对应专属图标，暂借鸦羽核心被动；信号爆发暂借鸦羽必杀。
